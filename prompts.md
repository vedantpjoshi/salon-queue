# Prompts Used

This file documents every prompt used to build the Glamour Queue salon management system.

## Prompt 1: Project Setup & Full Build
> Read the attached TA handout (canteen lab prompts and vibe coding guide).
> Develop a Vibe Coding Project for a Salon Queue Management System.
> Create all documentation (docs/01-brief.md, docs/02-screens.md, docs/03-flows-rules.md, AGENTS.md).
> Set up React + Vite + TypeScript + Tailwind CSS frontend with Express + Socket.IO + SQLite backend.
> Build all 6 screens: Services Menu, Cart, Token Status, Stylist Board, Now Serving Display, Admin Dashboard.
> Implement real-time updates via Socket.IO, daily token reset, forward-only status transitions,
> backend validation, responsive mobile-first design, and prepare for deployment on Render.

## Prompt 2: QA Audit
> Test the full end-to-end flow and fix any bugs found.

## Prompt 3: Deployment
> Deploy to Render and add the live link to README.md.

## Prompt 4: Free Deployment Preparation
> Keep all hosting and database services on their free plans. Configure Render Free and a hosted free PostgreSQL database, keep SQLite for local development, and ensure production refuses to write orders to ephemeral local storage. Do not enable paid disks or add-ons.
